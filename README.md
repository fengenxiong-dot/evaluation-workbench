# 评鉴 · 在线评价工作台

把线下 Excel 评价表变成可分配、可填写、可汇总的在线评价任务。

[项目主页](https://github.com/fengenxiong-dot/evaluation-workbench) · [作者与项目合集](https://github.com/fengenxiong-dot) · [许可证](LICENSE)

## 为什么做这个工具

在人力资源工作中，评价表经常通过 Excel 分发，回收后再手工汇总。不同评价人、不同对象及模板修改，会进一步增加管理成本。这个项目希望保留业务人员熟悉的表格布局，同时把评价任务和汇总流程放到同一个工作台。

## 核心功能

- 导入 Excel 评价表，保留合并单元格及基础表格样式。
- 可视化表格设计器，支持文字编辑、行列调整、合并拆分及评分字段设置。
- 配置评价维度、权重和分值，维护模板版本。
- 建立被评价对象、评价人和差异化登录码。
- 使用分配矩阵安排评价任务，评价人查看自己的待评对象。
- 在线填写评分与评语，按权重汇总并导出 CSV。

## 适合哪些场景

- 培训效果评价、项目评审与内部活动评价。
- 多位评委分别评价多个对象。
- 需要沿用原有 Excel 表格结构的内部评价流程。

## 第一次使用

### 准备环境

Node.js 22.13 或以上、npm 和现代浏览器。当前源码使用 Vite/Vinext 与 Cloudflare 本地运行时，持久化依赖 `DB` 绑定；仅启动页面不等于服务端共享数据已正常工作。

下载方式：会使用 Git 可按下面的命令克隆；也可在本页点击 **Code → Download ZIP**，解压后在项目目录打开终端，跳过 `git clone` 和 `cd` 两步。

### 安装与启动

```sh
git clone https://github.com/fengenxiong-dot/evaluation-workbench.git
cd evaluation-workbench
npm ci
npm run dev
```

打开终端显示的本地地址。若需要按仓库提供的容器方案试用，可在已安装 Docker Compose 的电脑运行 `docker compose up -d --build`，再访问 `http://127.0.0.1:3000`。该容器流程尚未在全新环境验收。

### 操作流程

1. 先使用虚构对象与评价人，新建或导入一份简单评价表。
2. 在模板设计器确认表格布局、评分单元格和权重。
3. 维护评价人及登录码，创建任务和评价关系。
4. 以评价人身份填写测试评分。
5. 检查汇总分数与 CSV 导出，核对计算口径。
6. 需要多人共享时，再检查 `/api/data` 服务端读写、持久化目录和访问控制。

## 当前状态与限制

当前开源副本补回了 `/api/data` 源码路由，但尚未完成全新环境构建与多人并发验收。后端不可用时，前端有浏览器本地存储回退，不能据此认定不同电脑已经共享数据。现有评价人登录码不等同于完整的服务器鉴权；不要直接把当前数据接口暴露到公网。

**验证情况：** 本次核对了页面入口、数据路由及数据库结构的文件依赖；未完成清洁环境构建。

## 数据保存与配置

本地开发运行时的数据位于 `.wrangler/`；容器方案映射 `server-data/`。浏览器回退数据位于当前浏览器 localStorage。

公开仓库只提供源码与示例配置。真实人员资料、业务文件、数据库和 API Key 需要由使用者自行管理。先用虚构数据走通流程，确认符合自己的需求后再投入实际工作。
