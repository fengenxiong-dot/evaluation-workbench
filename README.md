# 评鉴 · 企业内网评价工作台

用于把线下评价表转换为局域网内可共享的在线评价任务。模板、任务、评分和汇总结果统一保存在服务器数据库中，所有访问同一服务器的电脑共享数据。

## 功能

- 部署后由系统直接读取 Excel，保留合并单元格、行高、列宽、文字、基础样式和评分位置，按原表结构生成在线评价表（无需 Codex）
- 从 CSV 自动识别评价指标，也可手动配置维度、权重和分值
- 为多个被评价对象和评价人批量生成任务
- 预录评价人姓名、部门和差异化登录码
- 通过分配矩阵为每位评价人指定不同的评价对象
- 评价人登录后只显示自己的待评价对象
- 复制评价链接，填写评分与评语
- 自动按权重折算综合分，并按对象汇总排名
- 导出汇总 CSV
- 每 5 秒同步其他电脑提交的最新数据

## Excel 原表还原

管理员进入“评价表模板”，选择“新建或导入模板”，上传 `.xlsx` 或 `.xls` 文件即可。识别结果会连同表格布局一起保存到服务器数据库；后续创建任务、评委填写和服务器重启都不需要 Codex，也不需要保留上传电脑上的原文件。

系统会自动识别包含“分值/满分”和“合计/评分/得分”行的评价表，将合计行对应单元格转换为在线评分框，并自动绑定被评价人、评价人、考察期、综合得分、综合评价和签名日期。CSV 不包含合并单元格和样式信息，因此只能用于导入指标，不能用于严格还原版式。

## 类 Excel 表格设计器

管理员可以不上传文件，直接在“评价表模板”中新建可视化表格。设计器支持编辑文字、增删行列、Shift 框选、合并与拆分单元格、调整行高列宽、基础文字和背景样式，并可把任意单元格设置为评分或填写字段。行号和列标边界支持直接拖动，也可在右侧输入精确的行距、列距数值。Excel 导入后的表格也会进入同一设计器继续修正。

模板采用不可变版本：复制编辑现有模板时会生成更高版本，已经创建的任务仍然绑定原版本，避免历史评价表因后续修改而变化。

## 推荐：Linux + Docker 部署

Linux 服务器需预先安装 Docker 和 Docker Compose。将整个项目目录复制到服务器后，在项目目录执行：

```bash
docker compose up -d --build
```

浏览器访问：

```text
http://服务器局域网IP:3000
```

例如服务器地址为 `192.168.1.20`，则访问 `http://192.168.1.20:3000`。

数据库文件保存在项目目录的 `server-data` 文件夹中。升级容器不会清除该目录；请定期备份它。

常用维护命令：

```bash
# 查看运行状态
docker compose ps

# 查看日志
docker compose logs -f

# 重启
docker compose restart

# 停止
docker compose down
```

如果服务器开启了防火墙，需要允许局域网访问 TCP 3000 端口。正式使用时也可以通过公司现有 Nginx 反向代理到该端口。

## 不使用 Docker

服务器需要 Node.js 22 或更高版本：

```bash
npm ci
npm run build
npm run start
```

服务监听 `0.0.0.0:3000`，局域网内可通过服务器 IP 访问。

## 本机开发

```powershell
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。开发环境同样使用项目内的本地数据库模拟服务器共享数据。

## 当前权限说明

当前版本适用于可信公司内网：评价人通过差异化登录码进入个人待办页面，管理员后台暂未设置登录密码。登录码用于轻量身份区分；如果需要防止技术人员绕过页面读取接口数据，或需要接入公司统一身份认证，应继续增加服务端会话、管理员登录和角色权限校验。
